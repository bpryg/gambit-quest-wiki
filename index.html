毒・燃焼・ガチャの最新仕様

出典：提供された開発者パッチノート5枚。公開済みのv0.94.29・v0.94.34・v0.94.35と、バージョン表記のない燃焼変更告知を整理。v0.95の名称変更は未反映の予定として掲載しています。

毒・燃焼・死の宣告には能力値上限がある

v0.94.29（Version186）で、割合ダメージは「従来の割合ダメージ」と「付与者のステータス×係数」の小さい方になりました。ステータスは力・魔・技のうち最も高い値です。敵HPが大きいほど無制限に伸びるわけではありません。

効果割合側v0.94.29の上限
毒・1ティック最大HP×2%×スタック（ボス：0.5%×有効スタック）ステータス×2×有効スタック
燃焼・1ティック当時は最大HP×4%（ボス1%）当時はステータス×2。下記の秒単位化後の係数は未確認
死の宣告残りHP×40%（ボス12%）ステータス×30

破滅・不死の置き土産・ラストスタンドは、もともと魔・味方の最大HP・力などを参照するため、この割合ダメージ修正では変更なし。各種強化・耐性の適用順や、別のキャラが付与した毒の扱いは未確認です。

毒は敵の行動、燃焼は経過時間でダメージ

燃焼の追加告知では、1秒ごとに最大HPの1%（ボス0.25%）へ変更。従来の1ターン＝4秒ぶんと割合の合計は同じですが、鈍足・ストップ・凍結中もダメージが進みます。告知のバージョン番号と、秒単位化後の能力値上限係数は確認できていません。

  • 毒：敵の行動時に発生。行動が速い敵ほど消化が速く、行動を止めると毒も進みません。
  • 燃焼：時間で発生。敵を遅くしたり止めたりしながら削る構成の候補です。

現在のビルド選び

毒役は成功率やスタック数に加えて、力・魔・技の最大値も確認しましょう。深層で毒が上限に達するなら、敵HPの増加だけを理由に毒特化を選ぶことはできません。弱点攻撃と同じWAVE・編成条件で、撃破時間とMP収支を比較してください。鈍足・行動停止を多用する編成では、時間で削る燃焼も比較候補になります。

記事内のW100到達・毒DPS・周回時間は当時の実測です。パッチ後の再現性や最適編成を保証する数値ではありません。報酬実測は残しますが、時間当たり効率は戦闘時間の変化により再検証が必要です。

ガチャの5個目以降は自動整理（v0.94.35）

v0.94.34（Version191）で同じスキルの手持ち上限と自動整理を導入。v0.94.35（Version192）では最初の4個を残し、5個目以降だけを、上限未到達の中で最もLvが高い個体へ合成するよう修正されました。ロックした個体は整理対象外。合成後も4個を超える場合は安いものから魔石化されます。

初心者向け：序盤フローチャート

序盤の最初のチェックポイントはW10、次のマップ解放目標はW20突破。初期の4人で始め、持っている装備とスキルで役割を分けよう。以下は既存の戦闘仕様・攻略記録をもとにした推奨手順で、クリア保証ではない。

最初の進め方

序盤は「準備 → W10突破 → W20突破 → 次のマップ解放」を大きな流れとして覚えればOK。負けたときだけ、戦闘履歴を見て原因を1つずつ直す。

装備と役割を決める

空き装備を埋める。回復役は回復を優先し、最後に通常攻撃などMPがなくても動ける行を残す。

  • MP切れ → 高コスト技を減らす / 防御でMPを戻す

  • 火力不足 → 弱点を狙う / レベル・装備を見直す
  • ボスの大技 → デスペル所持後は「ため」解除を検討
  • 何も行動しない → 最後に成立しやすい通常攻撃行を置く

W20突破 → 次のマップへ

W20を突破したら次のマップが解放。新マップが苦しければ、前のダンジョンへ戻って育成・装備・ガンビットを調整。

W10を越えたら：次はW20

1. ボス後のバフを選ぶ。安定しない間は、稼ぎ倍率だけでなく生存・MP維持を重視。

2. 戦闘履歴を確認し、同じ構成で安定して突破できるか再挑戦。

3. W20突破を目標にそのダンジョンを先へ進む。W20突破で次のマップが解放される。苦しければ安定する場所へ戻る。

4. ガチャ・合成・転職は、回復不足や火力不足など今の課題に合わせて検討。同じスキルの合成ではLvが加算される。必要な装備中・予備のスキルを確認してから行う。

各挑戦はW1から開始。ボス撃破時の装着スキルLvアップは「まれに」であり、毎回必ず上がるわけではない。

魔石：ボスラッシュの実測

洞くつのボスラッシュは5体撃破で一括報酬。初回は魔石1,496、再戦の記録は魔石112・JP248・基本G0。再戦は約30秒の記録があり、単純計算では魔石224/分。

これは1回の実測からの換算で、操作時間込みの長時間効率ではない。初回ボーナスを周回収益に混ぜない。112魔石への縛り倍率の適用は未確認なので、同じ数値が必ず出るとは限らない。解放条件はゲーム画面で確認。

再挑戦の操作時間を入れてもW10有利になりやすい

同じ再挑戦ロスが毎周かかる前提では、効率逆転の目安はJPで約32秒/周、魔石で約40秒/周。通常の再挑戦操作がこれより短ければ、この記録ではW10撤退ループが有利。

参考結論：純粋なJP・魔石/時間ならW10撤退→再挑戦。 W20まで行く理由はW20突破・解放条件・検証など、時間効率以外の目的がある場合。比較できる総時間は各1本なので、別ビルド・別レベルでは逆転の可能性あり。

基本ルール

ダンジョン進行

  1. ワールドマップで行き先を選んで「しゅっぱつ」。
  2. 毎回WAVE 1から開始。

原因の本命：デスペル用MPが枯れた

タンク役最大MPは50、デスペルはMP10。

W20中のタンク役は、

  • デスペル：MP10
  • プロテク：MP6
  • 挑発：MP0
  • 回転斬り：HP消費 を使用。

回転斬り・挑発ではMPが回復せず、通常攻撃や防御もほぼ使わないため、 一度デスペルを撃ったあとMPを補充できず、次の「ため」でデスペルが使用不能になった可能性が高い。

特にW20は敵が2体いるため「敵2体以上→回転斬り」が常時成立しやすく、 MP回復用の通常攻撃・防御までガンビットが降りにくい。

レベル上げなしで狙える改善

  1. ため中の敵 → デスペル
  2. 自分MP50%以下 → 防御
  3. 自分に挑発がない → 挑発
  4. 隊列2番目（魔法攻撃役） / 防御UPがない → プロテク、または魔法対策ならシェルを検討
  5. ボスに防御↓がない → かぶと割り
  6. 余り手番 → 防御
  7. 必要なら通常攻撃
  • W20では回転斬りを外す：敵2体条件が常時成立しやすく、MP回復行動を阻害するため。
  • 強撃も外す/低優先：タンク役の役割を火力より「ため解除＋耐久」に寄せる。
  • 防御は最大MPの10%を回復するため、タンク役なら1回約5MP回復。
  • MP50%以下で防御させれば、デスペルMP10を再確保しやすい。

もう一つの改善：随伴を先に落とす

今回のW20随伴はボムで、戦闘終了までかなり長く生存し、 呪文・爆炎で継続的に回復負担を増やしていた。

ボムも氷弱点なので、魔法攻撃役に

  • 敵が2体以上
  • 残HPが最も少ない敵
  • 氷柱

のような行をボス攻撃より上に置ければ、 HPの低い随伴を先に落とせる可能性が高い。

随伴処理後はドラゴン単体になり、

  • タンク役の回転斬り条件が消える
  • 回復役の回復負担が減る
  • 魔法攻撃役がドラゴンへ集中できる ため、安定性が上がる。

今回の失敗は「レベル不足」よりも、

  1. デスペル後のMP再確保ができていない
  2. 随伴ボムを長時間残している
  3. その結果、後半のメガフレアを止められず回復負担も高い

W30撤退の直接原因

最初の「力をためている」には、

  • ドラゴン：力をためている
  • タンク役：デスペル

  • ドラゴン：メガフレア

  • タンク役 150
  • 魔法攻撃役 310
  • 回復役 572…

で3人戦闘不能、撤退。

「間に合わなかった」のではなく、MP不足が本命

2回目のため中にもタンク役自身の行動順は1回来ている。 その行動でデスペルではなく挑発を選んでいるため、単純な速度不足ではない。

ガンビット上ではデスペルが挑発より上にあるため、 デスペルが使用不能だった可能性が非常に高い。

最有力はMP不足。

W30序盤では、

  1. プロテク（MP6）
  2. 1回目のデスペル（MP10）
  3. 通常攻撃を1回

という流れで、2回目の「ため」までにMPを十分戻せていない。

通常攻撃のMP回復は最大MPの3%。 タンク役最大MP50なら約1.5MPしか戻らないため、 デスペル1回分の10MPを再確保するには足りない。

W30向けの重要ポイント：ためを見てからMP回復では遅い

W30では「ため」後、タンク役に来た行動機会が実質1回だけだった。

そのため、

  • ため発生
  • MP不足なので防御
  • 次のターンでデスペル

という運用では、2回目のターンが来る前にメガフレアを撃たれる可能性が高い。

つまり必要なのは、 ドラゴンがため始める前から常にMP10以上を残しておくこと。

暫定W30用タンク役案

タンク役最大MP50、プロテクMP6、デスペルMP10を考えると、 MPを20前後で維持するのが安全。

特に MP40% = 20MP を下回ったら防御、という設定が噛み合う。

例：

  1. ため中の敵 → デスペル
  2. 自分MP40%以下 → 防御
  3. 自分に挑発がない → 挑発
  4. 魔法攻撃役 / 防御UPがない → プロテク
  5. 敵が2体以上 → 回転斬り
  6. 余裕時の攻撃
  7. 防御または攻撃

理由：

  • 20MPを維持できれば、プロテクで6MP使っても14MP残る
  • その状態なら突然「ため」が来てもデスペル10MPを即使用可能
  • 防御1回で約5MP回復するため、通常攻撃よりMP維持効率が高い

W30ではMPを「ためが来てから作る」のではなく、平常時から貯金しておくのが重要。

暫定対策

深層の遺跡では、

  1. シャーマンの回復を許すと戦闘が長期化しやすい
  2. 長期化すると挑発切れ・後衛被弾の事故回数が増える
  3. 後衛は深層の単発攻撃や会心で一気に倒される

という流れが危険。

可能なら、ガンビットで

  • シャーマンを優先して落とす
  • 残HPが少ない敵へ単体火力を集中して確実に数を減らす
  • 複数敵へのメテオだけで削り続けず、終盤は氷柱などの単体火力へ切り替える

といった「敵の数を早く減らす」方向が深層では重要になりそう。

ガンビット

仕組み

  • 行動ゲージがMAXになった瞬間に、上から順にガンビットを調べる。
  • 「対象」が見つかり、「状況」も満たした最初の行の「スキル」に行動が決まる。
  • 構え系の技（気合ため・無心・「構え：～」など）を置いた行は、ゲージが50%を超えた瞬間に判定され、手番を使わずに構える。
  • 構え系はゲージMAX時には飛ばされる。
  • 当てはまる行がない場合は手番を使わずMAXのまま待機し、条件を満たした瞬間に動く。
  • 番号を押すと、その行をON/OFFできる。
  • 番号を押したまま上下に動かすと、行を並べ替えられる。
  • ガンビットはプリセット保存できる。

今回の当たり候補

最優先：SR 反撃

  • 効果：20%で物理攻撃に反撃。
  • タンク役は挑発で単体攻撃を集めるため、はじまりの洞くつ深層のような物理攻撃が多い場所と特に相性がよい。

  • 効果：弱体を持つ敵への技が、その弱体の残りを+1ターン。
  • 毒・支援役は鈍足・毒系、魔法攻撃役は大呪詛を使うため、これらがゲーム内部で「弱体」扱いなら維持との噛み合いが非常に良い。
  • どの状態が「弱体」に含まれるかは未確認。対応する弱体なら、長期戦で張り直し回数を減らせる可能性があり深層向け。

  • 効果：味方1人に8ターン、行動のたびHP5%回復。
  • タンク役へ維持できれば、回復役の単体ヒール回数を減らせる可能性がある。
  • 深層ではタンク役が通常攻撃を大量に受けるため、継続回復の価値が高い。
  • 回復役のアクティブ枠との交換になるため、裁きの光など攻撃枠との入れ替え候補。

かなり有用：SR 会心連鎖

ステータスの基本

HP

  • 最大HP。
  • 0になると戦闘不能。
  • 挑戦の間は自然回復しない。
  • タンク役例：最大HP 557、Lv+1で約+20。

MP

  • スキル使用で減る。
  • 通常の「攻撃」で最大MPの3%回復。
  • 「防御」で最大MPの10%回復。
  • アクティブスキルはLvが1上がるごとに、威力も消費MPも2%増える。
  • タンク役例：MP50なので攻撃1回で+1.5。防御は「ガードの心得」の+5%込みで+7.5。

力

  • 力参照スキルと、剣・刀・武器なしでの「攻撃」の威力元。
  • 会心ダメージ倍率にも影響。
  • 会心倍率への力補正：力÷400。
  • ゲーム内説明例：力40で+10%、力200で+50%。
  • タンク役例：力87、Lv+1で約+3、会心倍率×1.82。

守

  • 物理（力・技の攻撃）で受けるダメージを軽減。
  • 魔法には効かない。
  • 防御↓・攻撃↓・魔防↓など、ステータス低下系の弱体にもかかりにくくなる。
  • 弱体耐性側の式：1 − 守 ÷ (守 + 150)。
  • 目安：守20で物理-25%、守60で-50%、守120で-67%。
  • タンク役例：守64、物理で受けるダメージ-52%。

魔

  • 魔参照スキルと、杖・本での「攻撃」の威力元。
  • 最大MP補正：×(1 + 魔÷200)。
  • 例：魔20で+10%、魔100で+50%。

信仰

  • 信仰参照スキルの威力・回復量の元。
  • 回復量の基礎式：信仰×倍率 + 8。
  • 魔法で受けるダメージを軽減。
  • 毒・鈍足・暗闇などの状態異常にかかりにくくなる。
  • 状態異常耐性：信仰 ÷ (信仰 + 150)。
  • ステータス低下系の弱体耐性は信仰ではなく守。
  • タンク役例：信仰35、魔法ダメージ-37%、状態異常を19%防ぐ。

技

  • 技参照スキルと、短剣・弓・扇での「攻撃」の威力元。
  • 会心率補正：技÷1200。
  • 状態異常成功率補正：×(1 + 技÷100)。
  • 対象：毒・鈍足・暗闇・防御ダウンなど。
  • タンク役例：技26、会心率7%、状態異常成功率×1.26。

速

  • 行動ゲージがたまる速さ。
  • 多段技は速30ごとに回数+1。
  • 格闘家は速40ごとにさらに+1。
  • 目安：
    • 速10：約4.5秒に1回
    • 速40：約3秒に1回
    • 速90：約2.3秒に1回
  • タンク役例：速27、約3.4秒に1回（速度×1時）。

ダメージ計算

基本式：

参照ステータス × スキル倍率 × 相手の軽減 × ばらつき

相手の軽減：

60 ÷ (60 + 守 または 信仰)

ばらつき：

0.9 ～ 1.1

各種補正

  • 弱点：×1.5
  • 会心：×(1.6 + 会心ダメージ + 力÷400)
    • 物理のみ
    • 基本会心率：5% + 会心率補正 + 技÷1200
  • 暗闇：物理攻撃が半分はずれる
  • 鈍足：行動ゲージ速度 ×0.65
  • 攻撃UP：×1.3
  • 防御UP中の相手：×0.7
  • 防御中の相手：×0.5
  • 挑発中の相手：×0.7

敵は物理への硬さと魔法への硬さを別々に持つ。 ゲーム内説明例：ゴーストは物理に硬く、シャーマンは魔法に硬い。

今回のログでは、

  • 単体・弱点対象 → 氷柱
  • 敵が複数 → メテオ
  • MP調整 → 防御
  • 低コスト処理 → 氷

という形で動いている。

メテオは弱点を突かなくても全体に高めのダメージを出せるため、雑魚3体編成では氷柱を1体ずつ撃つより処理が速い。

役割分担の相性

  • 魔法攻撃役：氷弱点処理＋メテオ
  • 回復役：スケルトンへ光
  • 毒・支援役：毒・鈍足・ウォークライ
  • タンク役：挑発・防御ダウン

弱点を魔法攻撃役と回復役で分担できるため、火山の敵構成と非常に噛み合っている。

  • 雑魚戦からボス戦まで腐りにくい

  • 火山では4/5種が氷弱点なので対象が非常に多い

  • 高HPの長期戦では伸びる可能性がある
  • 固定・継続ダメージなので、高防御の敵に強い可能性
  • 毒の能力値上限とボスバフの計算順を確認してから、高WAVEでの評価を比較する

竜の火山W10周回なら、氷寄りが優勢。
