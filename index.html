初心者向け：序盤フローチャート

序盤の最初のチェックポイントはW10、次のマップ解放目標はW20突破。初期の4人で始め、持っている装備とスキルで役割を分けよう。以下は既存の戦闘仕様・攻略記録をもとにした推奨手順で、クリア保証ではない。

最初の進め方

序盤は「準備 → W10突破 → W20突破 → 次のマップ解放」を大きな流れとして覚えればOK。負けたときだけ、戦闘履歴を見て原因を1つずつ直す。

1

装備と役割を決める

空き装備を埋める。回復役は回復を優先し、最後に通常攻撃などMPがなくても動ける行を残す。

↓
2

はじまりの洞くつ W10を突破

W10は最初のボスチェックポイント。負けたら戦闘履歴を見て、原因を1つだけ直して再挑戦。

↓
3

W20を目指す

W10を越えたらそのまま同じダンジョンを先へ。次のマップはW20突破で解放される。

↓
4

W20で負けたら1つだけ修正

  • MP切れ → 高コスト技を減らす / 防御でMPを戻す
  • 回復不足 → ヒール行を攻撃より上へ
  • 火力不足 → 弱点を狙う / レベル・装備を見直す
  • ボスの大技 → デスペル所持後は「ため」解除を検討
  • 何も行動しない → 最後に成立しやすい通常攻撃行を置く
↓
5

W20突破 → 次のマップへ

W20を突破したら次のマップが解放。新マップが苦しければ、前のダンジョンへ戻って育成・装備・ガンビットを調整。

W10を越えたら：次はW20

1. ボス後のバフを選ぶ。安定しない間は、稼ぎ倍率だけでなく生存・MP維持を重視。

2. 戦闘履歴を確認し、同じ構成で安定して突破できるか再挑戦。

3. W20突破を目標にそのダンジョンを先へ進む。W20突破で次のマップが解放される。苦しければ安定する場所へ戻る。

4. ガチャ・合成・転職は、回復不足や火力不足など今の課題に合わせて検討。同じスキルの合成ではLvが加算される。必要な装備中・予備のスキルを確認してから行う。

基本・戦術

ゲーム概要

  • 4人パーティ制。
  • 仲間を直接手動操作するのではなく、ガンビット（対象 → 状況 → スキル）で行動を決める。
  • ワールドマップから行き先を選び、挑戦を開始する。
  • 各挑戦は WAVE 1から開始。
  • WAVEが進むごとに敵が強くなる。
  • 10WAVEごとにボスが出現する。

基本ルール

ダンジョン進行

  1. ワールドマップで行き先を選んで「しゅっぱつ」。

ステージ表示の「弱点」について

ステージ名の下に複数属性が表示されるが、現時点の実測ではそのステージ内の全敵が全部の属性に弱いわけではない。

例：はじまりの洞くつ（炎・雷・氷）

  • スライム：炎
  • コウモリ：雷
  • ゴブリン：氷
  • 毒グモ：炎
  • ゴーレム：氷

したがって、ステージ表示は「このステージで有効な弱点属性の一覧」として見るのが妥当。

追加例：竜の火山（氷・光）

  • スケルトン：光
  • ドラゴン：氷

この例でも、ステージ表示の属性が敵ごとに分散している。

  • タンク役の回転斬り条件が消える
  • 回復役の回復負担が減る
  • 魔法攻撃役がドラゴンへ集中できる ため、安定性が上がる。

W20対策案：タンク役をボス戦タンク特化

ボス戦ではタンク役の強撃を外し、タンク・妨害寄りにする案。

理由：

  • 現状タンク役のMPは余りやすい。
  • 強撃はHPを消費するため、長期ボス戦ではタンク本人の耐久を削る。
  • パーティ全体の主火力は魔法攻撃役が担っており、タンク役の直接火力を落としても影響が比較的小さい。
  • W20の主な負け筋はドラゴンの「力をためている→メガフレア」なので、デスペルの優先度が高い。

ボス戦ガンビット候補：

  1. ため中の敵 → デスペル
  2. 自分に挑発がない → 挑発
  3. 必要に応じて プロテク / シェル
  4. ボスに防御↓がない → かぶと割り
  5. 余った手番 → 防御 / 通常攻撃

特に、強撃を防御や補助に置き換えることで、HP消費を抑えつつMPを有効利用できる。

深層で目立った敵の硬さ

深層では、単純な被ダメージだけでなく敵のHPと回復量がかなり重くなっている。

シャーマンの「手当て」実測：

  • 自分を +837
  • スケルトンを +1127

一方、同時期の主な与ダメージ例：

  • 魔法攻撃役「メテオ」：シャーマン約150～181 / スケルトン約260～312
  • タンク役「回転斬り」：1体あたり約40～105
  • 回復役「裁きの光」：スケルトン約124～150（弱点）
  • 毒・支援役「鈍足の刃」：通常約50～100前後

そのため、シャーマンの回復1回で味方側の複数手番ぶんのダメージが戻される場面がある。

W48撤退の流れ

W47突破後、次WAVEで

  • スケルトン×2
  • ゴースト を確認。

ゴーストの「呪いの波動」と通常呪文に加え、 スケルトンの攻撃が後衛へ漏れた際のダメージが非常に大きい。

実測：

  • スケルトン → 回復役 537会心
  • スケルトン → 魔法攻撃役 276

最終的に3人戦闘不能となり撤退。

暫定対策

深層の遺跡では、

  1. シャーマンの回復を許すと戦闘が長期化しやすい
  2. 長期化すると挑発切れ・後衛被弾の事故回数が増える
  3. 後衛は深層の単発攻撃や会心で一気に倒される

という流れが危険。

可能なら、ガンビットで

  • シャーマンを優先して落とす
  • 残HPが少ない敵へ単体火力を集中して確実に数を減らす
  • 複数敵へのメテオだけで削り続けず、終盤は氷柱などの単体火力へ切り替える

といった「敵の数を早く減らす」方向が深層では重要になりそう。

ガンビット

仕組み

  • 行動ゲージがMAXになった瞬間に、上から順にガンビットを調べる。
  • 「対象」が見つかり、「状況」も満たした最初の行の「スキル」に行動が決まる。
  • 構え系の技（気合ため・無心・「構え：～」など）を置いた行は、ゲージが50%を超えた瞬間に判定され、手番を使わずに構える。
  • 構え系はゲージMAX時には飛ばされる。
  • 当てはまる行がない場合は手番を使わずMAXのまま待機し、条件を満たした瞬間に動く。
  • 番号を押すと、その行をON/OFFできる。
  • 番号を押したまま上下に動かすと、行を並べ替えられる。
  • ガンビットはプリセット保存できる。

今回の当たり候補

最優先：SR 反撃

  • 効果：20%で物理攻撃に反撃。
  • タンク役は挑発で単体攻撃を集めるため、はじまりの洞くつ深層のような物理攻撃が多い場所と特に相性がよい。
  • 防御役の仕事を続けながら追加ダメージを稼げるため、現編成ではかなり自然に入る。

最優先候補：R 弱体の重ね引き

  • 効果：弱体を持つ敵への技が、その弱体の残りを+1ターン。
  • 毒・支援役は鈍足・毒系、魔法攻撃役は大呪詛を使うため、これらがゲーム内部で「弱体」扱いなら維持との噛み合いが非常に良い。
  • どの状態が「弱体」に含まれるかは未確認。対応する弱体なら、長期戦で張り直し回数を減らせる可能性があり深層向け。

かなり有用：R リジェネ

  • 効果：味方1人に8ターン、行動のたびHP5%回復。
  • タンク役へ維持できれば、回復役の単体ヒール回数を減らせる可能性がある。
  • 深層ではタンク役が通常攻撃を大量に受けるため、継続回復の価値が高い。
  • 回復役のアクティブ枠との交換になるため、裁きの光など攻撃枠との入れ替え候補。

かなり有用：SR 会心連鎖

  • 効果：会心が出ると行動ゲージ+25。
  • 会心が比較的出ている毒・支援役と相性がよく、攻撃・弱体付与の回転をさらに上げられる可能性がある。
  • R 会心の貯金（会心が出なかった攻撃ごとに会心率+5%、会心でリセット）と組み合わせる価値もある。

ステージ・構成次第で有用

SR 火炎嵐

  • 敵全体に炎、30%で燃焼。
  • はじまりの洞くつではスライム・毒グモが炎弱点なので、複数敵にこれらが混ざるWAVEで候補。
  • ただし現在のメテオが非常に強いため、実戦比較するまでは置き換え確定ではない。

R 毒の絵具

  • 毒5スタック以上の敵には弱体が必ず入る。
  • 毒寄せを続けるなら、大呪詛・鈍足などを確実に通すための補助候補。
  • 5スタック到達までが必要なので、短期戦では価値が落ちる。

SR 時間停止の契約

  • 敵全体ゲージ-30、味方全員ゲージ-15。
  • 全体で見ると敵側をより大きく遅らせるため、複数敵の事故防止候補。
  • ただしタンク役のデスペルや回復役の回復も遅れるため、ボスの「ため」中に雑に使うのは危険。要実戦検証。

R 会心の貯金

  • 会心が出ない攻撃ごとに会心率+5%、会心で0に戻る。
  • 会心連鎖とセットで毒・支援役の回転補助候補。
  • 単体では安定化寄りで、即効性はSR会心連鎖より低め。

SR 満身の力

  • 行動を使わない構え。次の技に、減っているHP割合ぶん威力を上乗せ。
  • 低HP時の爆発力は高いが、深層オートでは「瀕死を維持する」こと自体が危険。
  • 手動ボス・短期決戦向けの候補。

現編成では優先度低め

SR 弔い合戦

  • 倒れている味方1人ごとに威力+25%。
  • 深層では発動機会自体はあるが、味方が倒れている状況では火力より蘇生・立て直しの方が重要。

SR 屍の誓い

  • 倒れている味方人数×魔×0.8の暗黒攻撃。誰も倒れていなければ×0.3。
  • 平常時の倍率が低く、現編成では事故後専用になりやすい。

SR 捨て身

  • 威力2.5だが、次の敵の行動まで受けるダメージ2倍。
  • タンク役は被弾役なので特に危険。毒・支援役も現状は技寄りのため優先度低め。

SR 残心

  • 待機した後の行動はゲージ30%残り。
  • 現在のガンビットは基本的に常時使える下段行動があり、意図的な待機が少ないため活かしづらい。

SR 爆薬

  • 錬金術師系（予定）限定。敵全体に 敵の強さ×6+10 の固定ダメージ。
  • 現パーティでは職業条件の都合で即採用しにくい。

R 急所突き

  • 技参照の単体攻撃で会心が出やすい。
  • 会心連鎖との組み合わせは試せるが、毒・支援役はすでに鈍足・毒・加速など役割が多く、優先度は中以下。

HP

  • 最大HP。
  • 0になると戦闘不能。
  • 挑戦の間は自然回復しない。
  • タンク役例：最大HP 557、Lv+1で約+20。

MP

  • スキル使用で減る。
  • 通常の「攻撃」で最大MPの3%回復。
  • 「防御」で最大MPの10%回復。
  • アクティブスキルはLvが1上がるごとに、威力も消費MPも2%増える。
  • タンク役例：MP50なので攻撃1回で+1.5。防御は「ガードの心得」の+5%込みで+7.5。

力

  • 力参照スキルと、剣・刀・武器なしでの「攻撃」の威力元。
  • 会心ダメージ倍率にも影響。
  • 会心倍率への力補正：力÷400。
  • ゲーム内説明例：力40で+10%、力200で+50%。
  • タンク役例：力87、Lv+1で約+3、会心倍率×1.82。

守

  • 物理（力・技の攻撃）で受けるダメージを軽減。
  • 魔法には効かない。
  • 防御↓・攻撃↓・魔防↓など、ステータス低下系の弱体にもかかりにくくなる。
  • 弱体耐性側の式：1 − 守 ÷ (守 + 150)。
  • 目安：守20で物理-25%、守60で-50%、守120で-67%。
  • タンク役例：守64、物理で受けるダメージ-52%。

魔

  • 魔参照スキルと、杖・本での「攻撃」の威力元。
  • 最大MP補正：×(1 + 魔÷200)。
  • 例：魔20で+10%、魔100で+50%。

信仰

  • 信仰参照スキルの威力・回復量の元。
  • 回復量の基礎式：信仰×倍率 + 8。
  • 魔法で受けるダメージを軽減。
  • 毒・鈍足・暗闇などの状態異常にかかりにくくなる。
  • 状態異常耐性：信仰 ÷ (信仰 + 150)。
  • ステータス低下系の弱体耐性は信仰ではなく守。
  • タンク役例：信仰35、魔法ダメージ-37%、状態異常を19%防ぐ。

技

  • 技参照スキルと、短剣・弓・扇での「攻撃」の威力元。
  • 会心率補正：技÷1200。
  • 状態異常成功率補正：×(1 + 技÷100)。
  • 対象：毒・鈍足・暗闇・防御ダウンなど。
  • タンク役例：技26、会心率7%、状態異常成功率×1.26。

速

  • 行動ゲージがたまる速さ。
  • 多段技は速30ごとに回数+1。
  • 格闘家は速40ごとにさらに+1。
  • 目安：
    • 速10：約4.5秒に1回
    • 速40：約3秒に1回
    • 速90：約2.3秒に1回
  • タンク役例：速27、約3.4秒に1回（速度×1時）。

ダメージ計算

基本式：

参照ステータス × スキル倍率 × 相手の軽減 × ばらつき

相手の軽減：

60 ÷ (60 + 守 または 信仰)

ばらつき：

0.9 ～ 1.1

各種補正

  • 弱点：×1.5
  • 会心：×(1.6 + 会心ダメージ + 力÷400)
    • 物理のみ
    • 基本会心率：5% + 会心率補正 + 技÷1200
  • 暗闇：物理攻撃が半分はずれる
  • 鈍足：行動ゲージ速度 ×0.65
  • 攻撃UP：×1.3
  • 防御UP中の相手：×0.7
  • 防御中の相手：×0.5
  • 挑発中の相手：×0.7

竜の火山と氷の相性

実測した弱点：

  • マグマスライム → 氷
  • 溶岩グモ → 氷
  • ボム → 氷
  • ドラゴン → 氷
  • スケルトン → 光

つまり、現在確認できている火山の敵5種のうち、4種が氷弱点。

このため、氷柱をガンビットで弱点対象に優先して撃つだけで、かなり高いダメージ効率が出る。

実測例

  • マグマスライム：氷柱 412～466
  • 溶岩グモ：氷柱 523～624
  • ボム：氷柱 489
  • ドラゴン：氷柱 378～544
  • スケルトン：氷は弱点ではなく、光が弱点

メテオとの使い分け

今回のログでは、

  • 単体・弱点対象 → 氷柱
  • 敵が複数 → メテオ
  • MP調整 → 防御
  • 低コスト処理 → 氷

という形で動いている。

メテオは弱点を突かなくても全体に高めのダメージを出せるため、雑魚3体編成では氷柱を1体ずつ撃つより処理が速い。

役割分担の相性

  • 魔法攻撃役：氷弱点処理＋メテオ
  • 回復役：スケルトンへ光
  • 毒・支援役：毒・鈍足・ウォークライ
  • タンク役：挑発・防御ダウン

弱点を魔法攻撃役と回復役で分担できるため、火山の敵構成と非常に噛み合っている。

毒・破滅との比較

氷寄りの強み

  • 弱点倍率を即座に取れる
  • 雑魚戦からボス戦まで腐りにくい
  • 毒や破滅のように「効果が出るまで待つ時間」がない
  • 火山では4/5種が氷弱点なので対象が非常に多い

毒・破滅の強み

  • 高HPの長期戦では伸びる可能性がある
  • 固定・継続ダメージなので、高防御の敵に強い可能性
  • 将来の高WAVEや毒系ボスバフ次第では評価が逆転する可能性あり

現時点の評価

竜の火山W10周回なら、氷寄りが優勢。

毒・破滅は「W10を早く回す」より、さらに深いWAVEや高HPボス向けの研究対象として残す。

暫定ガンビット案

魔法攻撃役：

  1. 敵が2体以上 → メテオ
  2. 氷が弱点の敵 → 氷柱
  3. 氷が弱点の敵 / MP節約時 → 氷
  4. MP不足 → 防御
  5. ボス用の補助枠 → 大呪詛などを必要に応じて採用

回復役：

  • 光弱点の敵 → 裁きの光 / 光の矢
  • 回復が必要 → ヒール系
  • それ以外 → 防御
